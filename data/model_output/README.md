# Model output

Generated by `run_assessment.R` and the exploration scripts. Two subfolders:

- `saved_models/` — fitted SPiCT objects (`.rds`) per model variant.
- `spict_summaries/` — small summary objects extracted via `sumspict.*()` for the advice sheet.

Naming: `<variant>_{{STOCK_NAME_LOWER_SNAKE}}_spict_{{ASSESSMENT_YEAR}}.rds`.
