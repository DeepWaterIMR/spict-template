# data/output/

Derived objects: the compiled catch and index series, the fitted model, the retrospective and
hindcast peels, the management scenarios, and the small summary object the chapter and the
advice sheet read. **Nothing here is committed** — it is all regenerable.

Expensive steps cache here and are controlled by document parameters. **A cache that outlived
its fit is worse than no cache**: when the data, the priors, or the settings change, delete
this folder rather than trusting the toggles.
